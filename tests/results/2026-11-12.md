# Test set results — Nov 12, 2026

23 scam stores reported in Oct–Nov 2026 (MalwareTips, BBB Scam Tracker, Trustpilot) and 25 real stores, run fresh through the live check.

- **Before fixes:** Scam stores (23): **13 red**, 9 yellow, 1 green (missed). Real stores (25): **14 green**, 11 yellow, 0 red (false alarm).
- **After fixes:** Scam stores (23): **16 red**, 7 yellow, 0 green (missed). Real stores (25): **25 green**, 0 yellow, 0 red (false alarm).

## What changed
- Domain age now asks the registry directly (rdap.org was rate-limiting us, so most .com stores came back "couldn't verify").
- Flags the checkout software shared by a network of fake shops.
- Counts a Chinese domain registrar as a ships-from-China sign; three or more signs weigh more.
- Catches an old domain with a brand-new catalog (expired-domain trick), only when the whole catalog is visible.
- No popularity credit for top-million sites under 2 years old (ad-driven fake shops get traffic too).
